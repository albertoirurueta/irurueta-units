Installation

Irurueta Units is published as a Maven artifact with group id com.irurueta and artifact id irurueta-units. The project itself is built as a Java 21 Maven JAR.

Maven

<dependency>
    <groupId>com.irurueta</groupId>
    <artifactId>irurueta-units</artifactId>
    <version>1.4.1</version>
</dependency>

If you are consuming a snapshot build from this checkout, use the repository version shown in pom.xml, for example 1.5.0-SNAPSHOT.

Gradle

dependencies {
    implementation("com.irurueta:irurueta-units:1.4.1")
}

Imports

All runtime types live in the com.irurueta.units package:

import com.irurueta.units.Distance;
import com.irurueta.units.DistanceConverter;
import com.irurueta.units.DistanceFormatter;
import com.irurueta.units.DistanceUnit;
