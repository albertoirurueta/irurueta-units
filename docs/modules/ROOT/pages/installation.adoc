= Installation
:description: Add Irurueta Units to a Java project.
:repo-base: https://github.com/albertoirurueta/irurueta-units/blob/1.4.0/src/main/java/com/irurueta/units
:javadoc-base: https://albertoirurueta.github.io/irurueta-units/mvn-site/apidocs/com/irurueta/units

Irurueta Units is published as a Maven artifact with group id `com.irurueta` and artifact id `irurueta-units`.
The project itself is built as a Java 17 Maven JAR.

== Maven

[source,xml]
----
<dependency>
    <groupId>com.irurueta</groupId>
    <artifactId>irurueta-units</artifactId>
    <version>1.4.0</version>
</dependency>
----

If you are consuming a snapshot build from this checkout, use the repository version shown in `pom.xml`, for example `1.4.0-SNAPSHOT`.

== Gradle

[source,kotlin]
----
dependencies {
    implementation("com.irurueta:irurueta-units:1.4.0")
}
----
